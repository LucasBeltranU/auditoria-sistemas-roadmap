# Linux

## Objetivo
Documentar laboratorios de administracion y auditoria en Linux, usando Ubuntu Server y Kali Linux como base.

## Primer laboratorio
- Verificar usuarios, grupos y permisos.
- Revisar servicios activos.
- Identificar red, interfaces y rutas.
- Registrar evidencia de la configuracion inicial.

## Comandos utiles
- `whoami`
- `id`
- `ls -la`
- `ps aux`
- `systemctl list-units --type=service`
- `ip a`
- `ss -tulpn`

## Evidencias
- Capturas del terminal.
- Salida de comandos relevantes.
- Notas de hallazgos o debilidades.

Describe aqui la version del sistema, hostname, IP y cambios realizados.
