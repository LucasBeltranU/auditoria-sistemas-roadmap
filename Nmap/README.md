# Nmap

## Objetivo
Documentar exploracion de hosts, puertos y servicios usando Nmap de forma controlada.

## Primer laboratorio
- Identificar el objetivo o rango de prueba.
- Ejecutar un escaneo basico de puertos.
- Detectar servicios y versiones.
- Registrar resultados y posibles riesgos.

## Comandos utiles
- `nmap -sS -Pn <objetivo>`
- `nmap -sV <objetivo>`
- `nmap -O <objetivo>`
- `nmap -A <objetivo>`

## Evidencias
- Salida del escaneo.
- Lista de puertos abiertos.
- Hallazgos sobre servicios o versiones.

## Nota del laboratorio
Indica alcance autorizado, objetivo escaneado y fecha del analisis.
