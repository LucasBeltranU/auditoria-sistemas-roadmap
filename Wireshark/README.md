# Wireshark

## Objetivo
Documentar capturas de trafico, analisis de paquetes y hallazgos de red usando Wireshark.

## Primer laboratorio
- Iniciar una captura controlada.
- Identificar trafico DNS, HTTP, HTTPS e ICMP.
- Aplicar filtros de visualizacion.
- Guardar capturas y hallazgos.

## Filtros utiles
- `dns`
- `icmp`
- `http`
- `tcp.port == 80`
- `ip.addr == 192.168.1.10`

## Evidencias
- Archivo de captura si aplica.
- Capturas de filtros.
- Comentarios sobre paquetes relevantes.

## Nota del laboratorio
Registra la interfaz capturada, el tiempo de captura y el objetivo del analisis.
