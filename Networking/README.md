# Networking

## Objetivo
Documentar practicas de redes basicas y de auditoria, enfocadas en conectividad, direccionamiento y diagnostico.

## Primer laboratorio
- Confirmar direccion IP, puerta de enlace y DNS.
- Probar conectividad con `ping` y `tracert`.
- Identificar puertos abiertos y servicios expuestos.
- Guardar resultados como evidencia.

## Comandos utiles
- `ipconfig /all`
- `ping`
- `tracert`
- `nslookup`
- `netstat -ano`
- `arp -a`

## Evidencias
- Capturas de respuestas de red.
- Tabla con IP, mascara, gateway y DNS.
- Observaciones sobre latencia o fallos.

## Nota del laboratorio
Anota el escenario probado: host, VM, red NAT o puente, y resultado esperado.
