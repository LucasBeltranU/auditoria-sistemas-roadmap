# OWASP

## Objetivo
Documentar pruebas de seguridad web basadas en OWASP Top 10 y practica de identificacion de fallos comunes.

## Primer laboratorio
- Identificar la aplicacion o entorno vulnerable a evaluar.
- Enumerar formularios, rutas y puntos de entrada.
- Registrar riesgos como autenticacion debil, inyeccion o control de acceso.
- Documentar evidencia con capturas y parametros usados.

## Comandos utiles
- Navegador con herramientas de desarrollo.
- Proxy de prueba si lo usas.
- `curl`
- `grep`

## Evidencias
- Capturas de peticiones y respuestas.
- Datos de entrada usados.
- Descripcion clara del impacto.

## Nota del laboratorio
Indica la aplicacion, version, objetivo de la prueba y si el entorno es local o remoto.
