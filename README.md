## Orden recomendado para la Semana 0

1. Crear el repositorio en GitHub.
2. Inicializar Git en esta carpeta o en la carpeta del proyecto que vayas a versionar.
3. Crear snapshots limpios de cada VM antes de hacer cambios.
4. Guardar en `Notes/` la configuración base de las VMs.
5. Usar las plantillas de `Templates/` en cada práctica.

## Reglas de trabajo

- Un laboratorio por carpeta.
- Un informe por práctica.
- Un hallazgo por archivo cuando tenga impacto propio.
- Guardar capturas y evidencias junto al laboratorio correspondiente.
